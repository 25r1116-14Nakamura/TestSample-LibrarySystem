## バグの概要

基本仕様書 4.6項には「その書籍が貸出中（未返却）の場合、削除はできない」とあるが、実際には削除が可能となっている。
これにより、貸出履歴テーブル（loan）には記録が残っているのに、書籍テーブル（book）では削除済み（is_deleted=1）となる不整合が発生する。

## 再現手順

1. 管理者 (`admin`) でログインする。
2. 在庫があり、かつ **現在一般ユーザーが貸出中の書籍** (例: `ID: 10`) を特定する。
3. 書籍一覧画面から、当該書籍 (`ID: 10`) の「削除」ボタンを押下する。
4. 削除確認ダイアログで「OK」を選択する。

## 期待される動作

* システムは「この書籍は現在貸出中のため削除できません」というエラーメッセージを表示し、削除処理を中断する。
* 書籍データは有効なまま残る。

## 実際の動作

* **エラーメッセージが表示されず、削除完了メッセージが表示される。**
* 該当書籍が一覧から消える（論理削除される）。
* 借りていたユーザーの「貸出履歴」画面を見ると、該当書籍のタイトルが表示されない、またはシステムエラーが発生する可能性がある。

## 環境

* OS: Windows 11
* Browser: Chrome 120.0
