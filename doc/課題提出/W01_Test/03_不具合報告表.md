title: "[書籍管理] 貸出中の書籍を削除できてしまい、貸出履歴と不整合が発生する"<br>
labels: critical, data-loss<br>
assignees: ''<br>

## バグの概要
基本仕様書 4.6項には「その書籍が貸出中（未返却）の場合、削除はできない」とあるが、実際には貸出中の書籍であっても削除操作が完了してしまう。
また、削除後にその書籍が検索結果から消えるだけでなく、貸出中のユーザーの履歴画面からも当該書籍の情報が消失（またはエラー表示）しており、論理削除ではなく物理削除が行われている疑いがある。

## 再現手順
1. 管理者 (`admin`) でログインする。
2. 在庫があり、かつ **現在一般ユーザーが貸出中の書籍** (例: `ID: 10`) を特定する。
3. 書籍一覧画面から、当該書籍 (`ID: 10`) の「削除」ボタンを押下する。
4. 削除確認ダイアログで「OK」を選択する。

## 期待される動作
* システムは「この書籍は現在貸出中のため削除できません」というエラーメッセージを表示し、削除処理を中断する。
* 万が一削除する場合でも、ユーザーの貸出履歴には情報が残るべきである（論理削除）。

## 実際の動作
* **エラーメッセージが表示されず、削除完了メッセージが表示される。**
* 該当書籍が一覧から消える。
* 借りていたユーザーの貸出履歴画面で、当該書籍のタイトルが表示されない等の不整合が発生している。

## スクリーンショット
(なし)

## 環境
- OS: Windows 11
- Browser: Chrome (最新版)
